# geoxpl scope.md
# What is included in the system

The purpose of the system is to display geography enhanced interactive maps which show the entire extend of geographical features.

The MVP of the system shows the path and extent of a geographical feature on an interactive map.



Audience:
This system assists anyone wanting to explore geographical features.



Location.

A feature is in scope when its authoritative or defensibly derived geometry intersects Victoria. Once eligible, GeoXpl processes and displays its complete defensible extent, including portions outside Victoria.

Searchable Geographical features.
Roads,
Routes
Rivers
National parks.

Displayed information on interactive map.
Path
Extent

Capabilities
The system has about searchable catalogue of geographical features which have been processed to establish extent and or path.
The system can in the background add new geographical features not already in the catalogue. The system should use both official and unofficial sources and give a measure of confidence about the path and boundaries it determines.
The system provides administrative functionality via web pages to manage background processing.
The system interacts with the user via web pages to display search functionality and then display search results.



Representative Acceptance Cases.
The path followed by Route 1.
The path folowed by The Great Ocean Road.
The path followed by the Murray River.
The extent of the Little Desert National parks


The route or extent of a feature is 1. obtained from official/authoritative sources in the first instance or 2. derived or inferred from  both official and non-official sources.
