#GeoXpl design-principles.md
#Specify high level considerations

Design Principle 1

Never invent geometry.

If a boundary is uncertain,
display uncertainty.

Design Principle 2

Every displayed feature
records its source.

Design Principle 3

Separate imported data
from derived data.

Design Principle 4
Don't repeat code. Reuse it.

Design Principle 5
Try to keep the code readable by humans

Design Principle 6
Match variable names to real world names where possible


Design Principle 7
Try to consider the extendability of the system from the start
