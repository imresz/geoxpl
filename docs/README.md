# GeoXpl --- Documentation Index

This directory is the normative MVP specification.

**Scope:** named rivers and valleys that intersect Victoria. Once
eligible, analysis continues into NSW or SA as far as the same feature
extends.

-   `mvp-requirements.md` --- user/admin capabilities and acceptance
    criteria.
-   `geographic-processing.md` --- production of geometries of geographical features.
-   `architecture.md` --- components and information flows.
-   `data-sources.md` --- approved datasets, licences and source rules.
-   `development.md` --- technology choices, standards and Codex rules.

## Normative priority

1.  MVP requirements
2.  Geographic processing
3.  Data sources
4.  Architecture
5.  Development

Material conflicts require an issue or ADR, not a silent assumption.

## Scope clarification

Although the requested filename description mentioned parks, the stated
feature scope is limited to rivers and valleys. **Parks are out of
scope** unless scope is explicitly changed.
