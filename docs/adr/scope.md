# geoxpl scope.md

This file sets the stage of development.
The test region is centered on Victoria and will include surrounds and additional geographic features which either originate or terminate in Victoria or are partially located in Victoria
The set of searchable geographical features for the MVP is limited to roads, rivers and national parks in and around Victoria. This list will grow.
Even though other features are described elsewhere, they should no the included yet.
The current stage is assessment of viability and clarity of documentation.
