# geoxpl

This file sets the stage of development.
The test region is centered on Victoria and will include surrounds and additional geographic features which either originate or temrinate in Victoria or are partially located in Victoria
The set of geographical features is limited to roads, rivers and national parks. This list will grow.
The MVP should be able to correctly identify roads and rivers in and around Victoria.
Even though other features are described elsewhere, they should no the included yet
The current stage is assessment of viability and clarity of documentation.
